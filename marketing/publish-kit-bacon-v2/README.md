Direction: classic white-faced bacon-hair avatar, black jacket over blue shirt, dark pants, white shoes; saturated colors, graphic outlines and simpler cel shading. Short headlines were chosen as the default pending user preference. The discovery image has an excited open-mouth expression; other images have the classic curved smile.

These are promotional illustrations, not gameplay screenshots. The shell, sand and hair still include stylized detail; the Golden ammonite is enlarged for thumbnail readability. Artwork depicts the game's activity and environment families rather than exact production models. No assets have been uploaded.

Exports were checked for dimensions and file size (all below 3 MB). Run export.py to regenerate exports from the saved generated originals.
