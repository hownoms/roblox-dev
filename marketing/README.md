generator and re-run it, so the art stays in sync with the game's layers, colours and pets.

## Regenerate

```bash
pip install pillow numpy            # Pillow ≥ 10, numpy ≥ 1.24
python3 tools/marketing/generate.py                 # everything (~1.5 min)
python3 tools/marketing/generate.py icon            # just the icon
python3 tools/marketing/generate.py thumbs          # thumbnails (or t1 / t2 / t3 / t4)
python3 tools/marketing/generate.py social badges store
```

- `tools/marketing/art.py` is the toolkit: supersampled canvas, outlined sticker sprites (pets,
  treasures, blocky hero), chunky title text, scenery and layer strata. Layer names and colours are
  copied from `src/shared/Config/Layers.luau`, and the palette from `Config/Theme.luau`. Update
  `art.LAYERS` if those change.
- `tools/marketing/generate.py` composes each image. Output is deterministic (fixed seeds); change
  the `seed=` argument for a different arrangement of particles and sparkles.
- Fonts live in `tools/marketing/fonts/` (Luckiest Guy for titles, Fredoka One / Lilita One;
  licences in `LICENSES.txt`). If they're missing, the generator falls back to DejaVu Sans Bold.
- Variants: `icon(text="DIG!")`, `thumb_rebirth(badge="UPDATE 1")`. Make 2–3 icon variants (e.g.
  different shirt colours or text) for Creator Hub icon A/B experiments.

## Upload

**Icon and thumbnails.** In Roblox Studio, open the place and go to **File → Game Settings → Basic Info**,
or use the web: **Creator Hub → Creations → (experience) → Configure → Basic Info / Thumbnails**.
Creator Hub menus get renamed now and then; look for *Icon* and *Thumbnails*.
- Icon: **512x512** PNG/JPG. Roblox rounds the corners, so keep important things away from them.
- Thumbnails: **1920x1080** (16:9), up to 10. Upload in order 1 → 4. The first one is the one shown
  most (search, sponsored ads, sharing).
- Use **Thumbnail / Icon experiments** (Creator Hub) once you have traffic, and keep the variant
  with the best CTR.

**Badges.** Go to **Creator Hub → (experience) → Associated Items → Badges → Create a Badge**. Upload
the 512x512 PNG (Roblox crops it to a circle, and the art is designed for that) and paste the name and
description from `STORE_PAGE.md`. Then paste the badge ids into `src/shared/Config/Badges.luau`; the
server already awards them.

**Game passes & developer products.** Creator Hub → (experience) → Monetization → Passes / Developer
Products. Upload the matching `store/` icon with each one:

## Moderation notes

- Every uploaded image goes through Roblox moderation, which can take minutes to a few hours.
  Rejected or pending images show a placeholder. Upload at least a day before launch.
- The art shows **only things that exist in the game**: layers, treasures, pet types, rebirth
  multipliers (+0.5x each, so x1.5 / x2 / x2.5 are real values), and 1,000 m to the Core. Pets are
  stylised marketing renders of in-game pets such as the Core Dragon, Phoenix, Golden Crab, Octopus,
  Seal, Alien Blob, Sea Turtle and Rainbow Starfish. If the in-game models look very different,
  consider replacing them with real screenshots, because "misleading thumbnails" is a common reason
  for ad rejection.
- No Robux imagery, no "free Robux", no real brands or other games' characters, no text that
  imitates Roblox UI. Keep it that way when you edit.
- Use "UPDATE 1" artwork only after the update is live.
