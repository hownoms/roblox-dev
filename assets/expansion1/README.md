`concepts/` contains generated design artwork. `ui/` contains local transparent PNG exports.
`models/` contains a Rojo-built place that constructs the real primitive assets on Play.
`previews/` contains review-only images, including offline geometry renders rather than
Studio screenshots. `verification/` records headless evidence and build checks.

All assets are saved locally. Roblox image IDs, Studio moving/contact/device validation,
event services and persistent trophy integration remain pending. The existing approved
marketing art is preserved. There is no new player marketing mascot in this kit; any later
promotional scene must retain the exact approved bacon-hair outfit. Players keep their own
avatars. Nothing was uploaded or published.
